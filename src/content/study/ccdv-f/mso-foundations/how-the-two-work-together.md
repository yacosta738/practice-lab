Because model choice and reasoning mode are independent, each can be set separately. A capable model
with reasoning off is fast and direct, while a smaller model with reasoning on spends more tokens to
think. The most demanding tasks pair a capable model with a higher effort setting. Module 2 teaches
the mechanics of enabling reasoning and handling the thinking blocks it returns. The decision of
which model to run, weighed against cost, latency, and quality, is taken up in Module 4.
