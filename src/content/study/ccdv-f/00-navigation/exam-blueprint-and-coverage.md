## Study priorities (derived, not official order)

1. **D2 – Applications and Integration (33.1%)**: the largest domain; do streaming, tool cycles,
   batches, request handling, SDK boundaries, configuration, lifecycle.
2. **D5 – Model Selection and Optimization (16.8%)**: tokens, thinking, caching, effort,
   quality/latency/cost evaluation.
3. **D1 – Agents and Workflows (14.7%)**: decide workflow vs agent, harness, subagents, memory and
   deployment.
4. **D6, D8, D7**: prompt/context handling, MCP and security; many exam scenarios cross domains.
5. **D3/D4**: lower weights but do not skip. Operational diagnostics and Claude Code semantics are
   differentiating skills.

### Matrix interpretation and limits

- The matrix is a source-based gap assessment of Practice Lab material, not proof of course
  completion or mastery. The five authenticated Skilljar modules remain gated as listed
  in [Course Access Coverage](../course-access-coverage/).
- AICG lesson excerpts are partial; only the domains and lessons identified above have reviewed body
  excerpts. An HTTP 200 response confirms availability only.
- The public YouTube transcript, gated course screens, and contents of the public Claude practice
  artifact were not reviewed as question/content sources. No third-party questions or lesson bodies
  were copied.
- Content priorities follow the agreed order D6, D8, D7, D3, D4. Maintenance findings for D2
  configuration and D5 dynamic pricing/caching are tracked separately in
  the [Knowledge Gap Backlog](../knowledge-gap-backlog/).

### Cross-certification source review (2026-11-26)

The CCDV-P and CCAO-F source topics were compared with this 25-competency matrix and the existing
CCDV-F notes. Foundations-level coverage already exists for orchestration, context engineering,
tool execution, streaming/recovery, structured outputs, prompt caching, human approval, security,
MCP, evaluation, debugging, Claude Code, reliability, and observability. The reviewed sources did
not establish a new CCDV-F objective gap, so no CCDV-F questions or existing question IDs were
changed.

Query rewriting, reranking, knowledge-index versioning, and provider-specific embedding modes remain
in the Professional-level study library. They were not promoted to Foundations content because the
current 25-objective matrix does not identify them as missing Foundations requirements. The source
decisions and limitations for this review are recorded in `docs/certification-content-review.md`.
