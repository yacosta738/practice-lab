## Study priorities (derived, not official order)

1. **D2 – Applications and Integration (33.1%)**: the largest domain; do streaming, tool cycles, batches, request handling, SDK boundaries, configuration, lifecycle.
2. **D5 – Model Selection and Optimization (16.8%)**: tokens, thinking, caching, effort, quality/latency/cost evaluation.
3. **D1 – Agents and Workflows (14.7%)**: decide workflow vs agent, harness, subagents, memory and deployment.
4. **D6, D8, D7**: prompt/context handling, MCP and security; many exam scenarios cross domains.
5. **D3/D4**: lower weights but do not skip. Operational diagnostics and Claude Code semantics are differentiating skills.
