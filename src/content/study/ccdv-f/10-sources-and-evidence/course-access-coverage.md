## What we have and what we have not

**Have:** the official blueprint; public learning objectives; existing first-screen notes from authenticated browsing; independent vendor documentation; original explanatory atomic notes; practical labs; unofficial practice questions.

**Do not have:** complete authenticated lesson text, private video/transcript bodies, later screens after each checkpoint, answer keys from internal quizzes, course-provided exercise files, exam item bank (confidential and explicitly excluded).

## Acquisition procedure when authenticated access is available

1. Open each module under your own authorized Skilljar session, complete checkpoints as the learner (do not bypass restrictions).
2. For each newly accessed lesson, record **screen title, objective, original paraphrase, specific technical claims, diagram/asset pointers, source URL and date**.
3. Create/update atomic notes only when new evidence contributes a distinct claim; do not bulk-copy copyrighted lesson bodies.
4. Verify each claim against live documentation when API behavior is version-sensitive.
5. Update the coverage table and [Knowledge Gap Backlog](../knowledge-gap-backlog/); link new notes from each domain MOC.
